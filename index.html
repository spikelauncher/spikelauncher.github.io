Вопросы

Коротко о главном

Какие версии Minecraft поддерживаются?
Все из каталога Mojang — релизы и снапшоты, от старых до последних. Spike сам подбирает Java под версию (8 / 16 / 17 / 21), для старых версий есть legacy-установщик Forge. В Lite версии с загрузчиками помечены буквами F, G, N.
Вся линейка бесплатная?
Да: Lite, Cactus 2 и Spike — 0 ₽, без рекламы и подписок. Spike и Cactus 2 открыты под GPL-3.0. Лучшая благодарность — звезда на GitHub.
Нужен аккаунт Microsoft?
Во всех версиях есть офлайн-профили без регистрации. В Spike дополнительно — authlib-injector для серверов со сторонней авторизацией. Вход Microsoft пока в планах.
Нужно ставить Java?
Spike: Java встроена в установщики, нужную версию под Minecraft ставит сам. Cactus 2 тоже ставит Java автоматически. Универсальный JAR Spike требует свою Java 21+.
Где скачать старые версии? Перенесутся ли миры?
Архив выше: Cactus 2 — на GitHub, Lite — на старом сайте и в канале. Миры и скины лежат в .minecraft и никуда не деваются; в Spike каждая сборка — отдельная папка, старые миры просто скопируйте в неё.
Проверка модов — это антивирус?
Нет, это локальная эвристика Spike по байткоду: запуск процессов, обфускация, автозапуск, вложенные JAR. Может ошибаться в обе стороны. А сам лаунчер ничего не удаляет с компьютера без явного согласия — сканер конфликтующих программ только предлагает.
Игра вылетела — что делать?
В Spike открой разбор запуска: он покажет ошибку и вероятный мод-виновник, даст проверить сборку без него в копии. Плюс всегда есть откат на точку восстановления. В старых версиях — сброс настроек и менеджер модов.
